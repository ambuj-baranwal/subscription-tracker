# Subscription Tracker

Subscription Tracker is a user-friendly web application built with Mantine UI that helps users manage their subscriptions efficiently. Key features include:

- **Create Subscriptions**: Easily add new subscriptions with details like name, cost, renewal date, and category.
- **Email Reminders**: Automatically sends email notifications for upcoming subscription renewals to keep users informed and avoid missed payments.
- **Intuitive Interface**: Leverages Mantine UI components for a modern, responsive design that works seamlessly across devices.

The app aims to simplify subscription management, reducing the hassle of tracking multiple services and ensuring timely renewals.
